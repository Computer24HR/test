# נודניק 5 – תזכורות חוזרות ליומן ולמשימות

גרסה חדשה של Nudnik Calendar Reminders, שנכתבה מאפס: Kotlin, Jetpack Compose ו-Material 3.
מותאמת לאנדרואיד 16 (targetSdk/compileSdk 36) ורצה על אנדרואיד 8.0 ומעלה (minSdk 26).

## היכולות

| יכולת באפליקציה המקורית | המימוש כאן |
|---|---|
| תזכורות חוזרות לאירועי יומן | `NudnikEngine` – כל תזכורת ביומן מתחילה הצקה שחוזרת כל X דקות עד שהיא נסגרת |
| עובד עם כל יומן שמבוסס על Google Calendar (Jorte, Business Calendar…) | קריאה ישירה מ-`CalendarContract` (Instances + Reminders) |
| חלון קופץ | `PopupActivity` – מסך מלא, גם מעל מסך הנעילה (Full-screen intent) |
| צליל, רטט ונורית | ערוץ התראות דינמי, עם בחירת צליל, 3 דפוסי רטט וצבע נורית |
| ניעור לסגירה או לנודניק (דחייה) | `ShakeDetector` בחלון הקופץ |
| התראה על אירועים בלי תזכורת | "להציק גם על אירועים בלי תזכורת" + מספר דקות לפני האירוע |
| שעות שקטות | `QuietHours` – בשעות האלה מוצגת התראה שקטה, וההצקה מתחילה כשהן נגמרות |
| הגבלת מספר החזרות | "מספר חזרות מרבי" (0 = בלי הגבלה) |
| ניהול משימות | לשונית משימות עם מועד יעד ועדיפות. ההצקה ממשיכה עד שמסמנים "בוצע" (גם מתוך ההתראה) |
| נודניק (דחייה) | כפתור בהתראה, ובחלון הקופץ גם 5/15/30/60 דקות |
| ועוד | בחירת יומנים, התעלמות מאירועים של כל היום או מאירועים שדחית, עצירה כשהאירוע נגמר, החלקה שסוגרת את ההתראה, מתג כללי, בדיקת התראה |

## ארכיטקטורה

- **NudnikEngine** – נקודת כניסה אחת לכל הטריגרים: סורק את היומן מאז הסריקה הקודמת, מפעיל הצקות, מטפל בחזרות ובשעות השקטות, ומתזמן **התראה מדויקת אחת** (`setExactAndAllowWhileIdle`) לרגע הבא.
- **Room** – הטבלאות `tasks` ו-`alerts` (שומרות את מצב כל הצקה, כך שאפשר להמשיך אחרי אתחול).
- **DataStore** – ההגדרות.
- **WorkManager** – רשת ביטחון: ריצה כל 15 דקות, וגם ריצה מיידית כשהיומן משתנה (Content URI trigger).
- **Receivers** – אתחול המכשיר, עדכון האפליקציה, שינוי שעה או אזור זמן, קבלת הרשאת התראות מדויקות, `EVENT_REMINDER` של היומן, וכפתורי ההתראה.

## בנייה

1. פותחים את התיקייה ב-Android Studio (גרסה עדכנית) ב-**File › Open**.
2. Studio יוריד את Gradle 8.14.3 ואת התלויות. אם הוא מציע לעדכן גרסאות ב-`gradle/libs.versions.toml`, אפשר לאשר.
3. **Run** – או `./gradlew assembleDebug` (קובץ ה-wrapper jar ייווצר אוטומטית בפתיחה ב-Studio, או עם `gradle wrapper`).

## הרשאות

`READ_CALENDAR`, `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `USE_FULL_SCREEN_INTENT`, `RECEIVE_BOOT_COMPLETED`, `VIBRATE`.
במסך הראשי יש כרטיס שמבקש כל הרשאה חסרה, כולל החרגה מחיסכון בסוללה (מומלץ מאוד ב-Samsung וב-Xiaomi).

> לפרסום ב-Google Play: מאז אנדרואיד 14, `USE_FULL_SCREEN_INTENT` ניתנת אוטומטית רק לאפליקציות שעון מעורר ושיחות. באפליקציה הזו המשתמש מאשר אותה במסך ההגדרות (הכרטיס בראש המסך מוביל לשם).
